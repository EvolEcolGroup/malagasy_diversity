\subsection{Mindis parameter notes}\label{mindis-parameter-notes}

mindis: 0.005 - minimum genetic distance (in Morgans) at which to start
curve fitting (default: determined using LD correlation).
\url{https://comppopgenworkshop2019.readthedocs.io/en/latest/contents/06_alder/alder.html}
States that the default calculates the correlation in LD decay between
the target and each reference, and uses `the minimum distance that shows
no correlation in both references.' `If it continues beyond 2 cM (due to
either a strong bottleneck or admixture in a reference), the program
aborts.'

If mindis is automatically chosen, some runs fail with: `too much
long-range LD; not plotting LD curve' `fit start = inf because of
long-range LD correlation; exiting'

For Borneo-Esan, the failing runs are Betsileo and Merina/Merina A. This
is likely due to strong bottleneck in Asian ancestry component, given
that it fails only for populations with a larger Asian ancestry
component.

Dai-Esan is successful for all populations, regardless of mindis
setting.

\subsection{Other parameters}\label{other-parameters}

checkmap: YES binsize: 0.0005 default - genetic distance resolution (in
Morgans) - the size of bins that MALDER splits the genome up into, used
to calculate the distance between the bins of two snps as opposed to the
distance between the each individual pair of snps, for computational
efficiency jackknife: YES - outputs results from
leave-one-chromosome-out jackknifing

\section{Check for multiple admixture
events}\label{check-for-multiple-admixture-events}

malder begins by assuming a single wave of admixture, then:

``1. Add a new exponential term to the model. 2. Fit the model by
alternately optimizing all exponential decay terms and amplitudes. 3.
Calculate standard errors on all terms using a jackknife. 4. If all
decay terms have a p-value less than 0.01, go back to step 1, otherwise
finish.'' Pickrell et al.~2014

Sources of admixture at each wave can then be inferred if multiple waves
are present.

malder README at \url{https://github.com/joepickrell/malder} states:
`The output will be printed to the screen, with lines starting with
RESULT\_X being the results from fitting X curves to the data. The
program will always fit one more curve than is necessary, so if you get
RESULT\_3, then the lines that start with RESULT\_2 are the ones you're
interested in.'

Therefore, a RESULT\_2 across log files indicates a single wave is best
fit, while RESULT\_3 indicates multiple waves.

\section{Example LD curve plots}\label{example-ld-curve-plots}

`Weighted LD curves computed on real populations often exhibit a nonzero
horizontal asymptote contrary to the exact exponential decay formulas we
have derived above. Such behavior can be caused by assortative mating
resulting in subpopulations structured by ancestry percentage in
violation of our model. We show in Appendix A that if we instead model
the admixed population as consisting of randomly mating subpopulations
with heterogeneous amounts α---now a random variable---of mixed
ancestry, our equations for the curves take the form' (Loh et al 2013)

\[
E[a(d)] = M e^{-nd} + K
\]

`We fit discretized weighted LD curves as from Equation 9, using
least-squares to find best-fit parameters.' (Loh et al 2013)

`the affine term K\ldots arises from the presence of subpopulations with
differing ancestry percentages'.

The following plotting code is adapted from
\url{https://comppopgenworkshop2019.readthedocs.io/en/latest/contents/06_alder/alder.html}
Which describes as: E{[}Y{]} = M times e ~\^{}-nd + K

Adjusting the parameters ref\_a and ref\_b will print all LD curves for
this combination.
